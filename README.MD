# Estarmy — joyería y bijouterie unisex

Tienda virtual simulada con envíos a las localidades del Impenetrable, Chaco. Proyecto del Proyecto Integrado Interdisciplinar 2026 (EcoStart IA) de la Tecnicatura Superior en Desarrollo de Software del IES "René Favaloro".

> Es un proyecto de simulación académica: los productos, precios y datos son ficticios.

## Contenido del repositorio

- `index.html`: página principal y catálogo.
- `politica-privacidad.html`: política de privacidad (Ley 25.326 y Habeas Data).
- `styles.css`: hoja de estilos responsive (Flexbox y CSS Grid, sin frameworks).
- `productos.json`: catálogo con los campos `id`, `nombre`, `descripcion`, `precio_simulado`, `imagen_ia_url` y `categoria`.
- `img/`: imágenes del catálogo, generadas con inteligencia artificial.
- `docs/`: carpeta técnica (informes, matriz de riesgos y Gantt).
